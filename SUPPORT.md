# Getting help

- **Questions and ideas:** [GitHub Discussions in ipso](https://github.com/ipsofacto-io/ipso/discussions). For the EDR format, use the [edr-spec discussions](https://github.com/ipsofacto-io/edr-spec/discussions).
- **Bugs and feature requests:** open an issue in the repository concerned, using its issue forms.
- **Security vulnerabilities:** follow the [security policy](https://github.com/ipsofacto-io/.github/blob/main/SECURITY.md).
- **Security support period:** the same [security policy](https://github.com/ipsofacto-io/.github/blob/main/SECURITY.md) states which releases receive security updates. Pre-GA support is best-effort, and only on the latest minor release of a product that publishes a GitHub Release. A repository with no GitHub Release is not a supported product line. From commercial general availability, each designated major or long-term support line has a 5-year security support period under Regulation (EU) 2024/2847. Commercial support agreements, when they exist, do not shorten that period.
- **Commercial support:** available from the private beta onwards; details will be published here. Commercial support service levels start at general availability, together with the statutory security support period.
