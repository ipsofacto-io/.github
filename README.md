# ipsofacto-io/.github

Organization profile and shared community health files for all repositories under [ipsofacto-io](https://github.com/ipsofacto-io).

GitHub automatically applies these default files to any repository in the organization that does not provide its own copy.

## Repository contents

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Public GitHub organization profile |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Contribution workflow, license tiers, and contributor terms |
| [`SECURITY.md`](SECURITY.md) | Private vulnerability reporting, 90-day coordinated disclosure, good-faith testing, support window, and release/SBOM verification |
| [`.well-known/security.txt`](.well-known/security.txt) | RFC 9116 security contact file for `https://ipsoplatform.io/.well-known/security.txt` (not applied by GitHub) |
| [`SUPPORT.md`](SUPPORT.md) | Support channels and security support window |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Issue forms for bugs, features, tasks, and decision proposals |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default pull request template |
| [`scripts/`](scripts/) | Validation scripts and tests for `security.txt` and `SECURITY.md`, run on every pull request and weekly by the `security-txt` workflow |
